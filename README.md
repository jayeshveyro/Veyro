# Veyro GitHub Website

Static HTML/CSS/JavaScript landing site for GitHub Pages.

## Publish
1. Create a GitHub repository such as `veyro-website`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Your GitHub Pages URL will appear there.

The form is demo-only and does not persist submissions. Connect it to a backend/form database before using it for real lender leads. Never put API secrets in `script.js`.
